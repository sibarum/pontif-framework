## This file is just pseudocode to illustrate how the type system could work.

## Module declaration at the top of the file
module spn.stdlib.numerics
## Optional version declaration. Versions can be numbered or named. Multiple versions of the same thing are allowed to exist simultaneously.
version "development prototype"
## The second part of the module declaration: imports
using type, prove
## type and prove are builtin keywords - but never free

## A void type, has no members, acts as a placeholder only
type Zero

## Define a non-void type by assigning a "constructor"
## A naive information-preserving constructor is generated by default (like Java record types)
## The | "OR" type operator
## The @ type is self-referential
## The constructor has 1 argument: s
## The return type is the type (@)
type Peano = (s->@|Zero)->@

## Another void type
type Halt

## This looks familiar...
type PrimitiveRecursive = (s->@|Halt)->@

## Compiles or not?
prove Peano is PrimitiveRecursive

## Yes

## Another example:

type Diverge = (s->@|Diverge)->@
prove Peano is Diverge

## Compiles or not?

## No:
