Welcome-page screenshots
========================

Drop one PNG per sample here, named <sample-id>.png. The sample ids come from
Samples.java (they match the .ptf filenames in ../samples/):

  interactive-window.png
  line-chart.png
  curves-2d.png
  surface-3d.png
  colormap-surface.png
  wireframe.png
  axes-saddle.png
  point-cloud.png
  layered-scene.png
  volume.png
  volume-normals.png
  sdf-sphere.png
  sdf-csg.png

Guidance:
  - Format: PNG (RGB or RGBA).
  - Aspect: landscape ~16:10 (e.g. 640x400). The thumbnail preserves the image's
    own aspect, so a consistent shape keeps the gallery tidy.
  - Capture: run each sample (Run / Window) and grab the rendered plot/scene window.

Until a PNG exists for a sample, its card shows a "screenshot pending" placeholder;
the gallery is fully functional without the images.
